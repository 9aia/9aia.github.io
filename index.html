Why GAIA

The missing layers between coding agents and the repositories they work on.

We're building the missing layers between coding agents and the repositories they work on: delivery (tamias, scarab, tarsi, bupha, hypha), memory (myco, kuda), process (sturn, cuora, tardigrada, mimus, cicada, lasius, sepia, peregrin), and interface (pavo). Open, minimal, composable. A stack agents can actually run on.
