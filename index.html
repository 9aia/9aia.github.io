Our Mission

We build open infrastructure so people and agents can own the AI that works for them.

We're building the missing layers between coding agents and the repositories they work on — a ledger (myco, kuda), a WAL (sturn), an orchestrator (peregrin, sepia), and a queue (mimus, cicada). Open, minimal, composable. A stack agents can actually run on.

How We Build

The principles behind how we build.

🔌

Ports Are the Architecture, Not a Plugin API

Every concern is a trait + impl; the boundaries are the codebase.

🤖

Machine-First Wire, Not UI-First

Manifest, schema, serve: surfaces for machines, humans second.

🔗

Composition Over Integration

Tools talk over ndjson/stdio wires. They embed, not integrate.

🌿

VCS-Native State

Durable state lives in versioned history, not a private DB.

📋

No Bespoke DSL

Config is the program, not a YAML pipeline language.

📦

One Binary, One Daemon — Not a Control Plane

A single process + a background service on any OS. The market answer is a server fleet + a dashboard.

🍽️

We Run on Ourselves

The suite manages its own development. Dogfooding is the test suite.

🏠

Own Your Stack

Open source, self-hosted. Your AI works for you, not the other way around.

🌱

Grown, Not Built

The engine emerges from use; the domain is a preset, not the product.

Our Products

The machines. Each a small engine, each owning one mechanism.

kuda

Code-map engine for agent workflows: crawls repos into verified per-module cards (repo card, module cards, symbol graph) that agents query instead of re-exploring.

Website

sturn

Ephemeral coordination engine for agents: claims, ops, and topics over the git object store, so agents see each other's intent in milliseconds instead of at merge.

Website

mimus

Verification engine and critic for repos and agent memory: extracts claims from docs, comments, and cards, verifies them against the code, and repairs the fixable.

Website

bupha

The CI integration for tamias: pluggable push sources queue per-sha pipeline runs on your box — GitHub first, GitLab later — with GitHub Actions workflows as a runner dialect. Ships as type: bupha tamias bundles.

Website

sepia

Session lifecycle engine for coding agents: one canonical IR and pluggable store drivers to list, load, attach, prompt, and resume sessions across agents (Devin, Claude Code, Cursor, and more).

Website

peregrin

Event-driven orchestration engine for agent workflows: declarative campaigns of events, nodes, and drivers across your machines, with a sepia-powered session plane on every node.

Website

myco

Records engine for agent work: a myco CLI owns every write to a repo's project/ ledger (todos, issues, proposals, plans, ADRs, handoffs). Markdown is canonical, git history is the audit trail.

Website

cuora

Secrets broker for agents: code carries cuora:// references instead of values, the CLI injects secrets as env vars at run time, and every materialization is audited.

Website

tarsi

Release plane: changelog → semver bump → tag → publish, shipped as type: tarsi tamias profiles driven by peregrin campaigns. Rewrite in progress.

cicada

Scheduled-work engine: declare calendars in YAML, plan and apply them against live providers with drift detection, ship calendar bundles through tamias, drive them from peregrin campaigns, plus an MCP server so agents can reconcile them.

Website

scarab

Config & template expertise: generic config loading (port/discovery/formats) and templated content packs distributed via tamias.

lasius

Git & workspace expertise for GitHub orgs: workspace gardener CLI (clone, sync, inspect, workspace files) plus the shared lasius-vcs port.

Website

tamias

Package and content manager for the agent factory: fetches, stores, caches, and dispenses content packages (peregrin bundles, myco kinds, kuda domains) via pluggable adapters.

Website

pavo

Visualization host for the 9aia tool suite: renders ViewNode IR trees emitted by tamias drivers across CLI, TUI, and web surfaces.

Website

hypha

Distributed substrate for agent workloads: a generic entity plane with namespaced ops, snapshots, and locks across your machines. Integrations plug in as entity kinds.

Website
