Why GAIA

The missing layers between coding agents and the repositories they work on.

We're building the missing layers between coding agents and the repositories they work on: packages (tamias), a ledger (myco, kuda), a WAL (sturn), an orchestrator (peregrin, sepia), and a queue (bupha, mimus, cicada). Open, minimal, composable. A stack agents can actually run on.
