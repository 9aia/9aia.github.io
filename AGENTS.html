Agent awareness ​

  • Session start / any work discussion: run myco status --prompt before proposing next steps — know the board first.
  • User describes new work → offer to capture it (myco todo add, issue new, proposal new). Don't wait to be asked.
  • Picking up a task: myco resume <ID> is the briefing.
  • Wrapping up: myco handoff <ID> anything resumable; keep statuses honest (claimed → in-progress → blocked/done).

Sturn awareness ​

  • No PRs. The pushed branch/commit is the deliverable; review streams continuously (sturn WAL), merge is a human/sturn call.
  • sturn-wired repo (sturn.toml present): sturn claim "<glob>" --ws <ws> before edits — claims surface conflicts in ms.
  • Ops via sturn write|rename|delete; sturn snap folds the ws into a real commit; sturn push publishes heads + refs/sturn/*.
  • sturn leave on exit — drops the actor's claims.
